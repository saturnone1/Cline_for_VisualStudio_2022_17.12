# Documentation

Architecture, compatibility, SDK coverage, and air-gap build documentation lives in this directory.

- `AiMaintenanceGuide.md` is the primary ownership and verification entry point for AI maintainers.
- `TargetArchitecture.md` records current invariants and the modular-monolith direction.
- `NamingConventions.md` defines source file naming rules and intentional exceptions.
- `GeneratedArtifacts.md` defines which generated outputs are tracked and how they are verified.
- `CleanArchitecture.md` is historical background for dependency direction, not the repository's organizing goal.
